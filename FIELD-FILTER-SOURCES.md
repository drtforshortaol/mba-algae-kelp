# Field filter evidence

Touch pools: giant kelp is documented at the Kelp Touch Pool in the Aquarium’s supplied Algae ID class recap. The date of the observation and a current station roster have not been confirmed. This is a documented example, not a live inventory.

Local coverage is a starter list based on SeaNet habitat records and the Aquarium’s Monterey Bay giant kelp account. Ulva is intentionally tagged at genus level.

- **Giant kelp** (*Macrocystis pyrifera*) — aquarium, pool, local. [Source](https://www.montereybayaquarium.org/animals-the-ocean/animals-a-to-z/giant-kelp).
- **Bull kelp** (*Nereocystis luetkeana*) — aquarium. [Source](https://www.montereybayaquarium.org/animals-the-ocean/animals-a-to-z/bull-kelp).
- **Dead man's fingers** (*Codium fragile*) — aquarium. [Source](https://www.montereybayaquarium.org/animals-the-ocean/animals-a-to-z/dead-mans-fingers).
- **Feather boa kelp** (*Egregia menziesii*) — local. [Source](https://seanet.stanford.edu/Ochrophyta).
- **Silva’s rockweed** (*Silvetia compressa*) — local. [Source](https://seanet.stanford.edu/rocky-shores).
- **Sea lettuce** (*Ulva spp.*) — local. [Source](https://seanet.stanford.edu/rocky-shores).
- **Turkish washcloth** (*Mastocarpus papillatus*) — local. [Source](https://seanet.stanford.edu/red).
- **Splendid iridescent seaweed** (*Mazzaella splendens*) — local. [Source](https://seanet.stanford.edu/red).
